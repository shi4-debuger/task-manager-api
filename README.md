# Task Manager Full-Stack App

A full-stack task management web application built with *FastAPI, **SQLAlchemy, **SQLite, and **HTML/CSS/JavaScript*.

## Features
- *JWT User Authentication:* Secure user signup, login, and password hashing (bcrypt).
- *Private Task CRUD:* Create, read, update, complete, and delete personal tasks.
- *Automated Testing:* End-to-end test suite using pytest and FastAPI TestClient.
- *Frontend UI:* Responsive single-page HTML/JS interface.
